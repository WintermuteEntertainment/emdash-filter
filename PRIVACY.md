# Privacy Policy — Em Dash Filter

**Effective date:** July 3, 2026

Em Dash Filter is a browser extension that finds em dashes in documents you
choose and produces a cleaned copy with punctuation replacements you approve.

## The short version

Em Dash Filter collects **no data at all**. Everything happens on your
computer.

## Details

- **No data collection.** The extension does not collect, store, or transmit
  any personal information, usage statistics, telemetry, or analytics.
- **Your files stay local.** Documents you open are processed entirely within
  your browser tab, in memory. They are never uploaded, and the extension
  makes no network requests of any kind.
- **No permissions.** The extension requests no browser permissions beyond
  opening its own page in a tab. It cannot read your browsing history, other
  tabs, or any website content.
- **No third parties.** There are no third-party services, libraries loaded
  from CDNs, advertising networks, or trackers. Every line of code ships
  inside the extension package and is open source.
- **No accounts.** There is nothing to sign up for and no server component.

## Verifying this

The complete source code is public:
https://github.com/WintermuteEntertainment/emdash-filter

You can confirm the extension makes no network requests by opening your
browser's developer tools (Network tab) while using it.

## Changes

If this policy ever changes (for example, if a future version adds an
optional online feature), the change will be noted in this repository's
commit history and in the extension's release notes before it takes effect.
